🔄 Đồng bộ & Sao lưu

1. Đồng bộ qua GitHub (dữ liệu lưu ngay trong repo)
❓ Cách tạo token (làm 1 lần, ~2 phút)
  1. Mở github.com/settings/personal-access-tokens/new
  2. Token name: quy12a6. Expiration: chọn dài nhất.
  3. Repository access → Only select repositories → chọn repo của lớp.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Bấm Generate token, copy rồi dán vào ô trên. Token chỉ nằm trong máy bạn, không nằm trong file.

Thủ quỹ sửa gì là tự ghi vào data.json trong repo. Bạn học chỉ cần mở link web bình thường, số liệu tự cập nhật (2 phút/lần). Không chia sẻ token cho ai.

2. Sao lưu ra file (.json)
3. Đồng bộ nhanh qua tin nhắn Zalo (Offline)
