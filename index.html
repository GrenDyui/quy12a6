🔄 Đồng bộ & Két Token không cần nhập lại

Trạng thái: ·

1. Két Token mã hóa AES-256 (Dùng ngay trên GitHub Pages)
⚙️ Tạo / Cập nhật Két Token mã hóa lên repo (làm 1 lần duy nhất)

Token GitHub của bạn sẽ được mã hóa AES-256-GCM (PBKDF2 600.000 vòng) rồi lưu thành vault.json ngay trong repo. Từ đó mở trên điện thoại hay máy khác chỉ cần nhập mật khẩu này, không bao giờ phải add lại Token!

2. Kết nối GitHub (lưu bền bằng IndexedDB + localStorage)
❓ Cách tạo Fine-Grained Token (làm 1 lần, chọn hạn tối đa 1 năm)
  1. Mở github.com/settings/personal-access-tokens/new
  2. Repository access → Only select repositories → chọn quy12a6.
  3. Repository permissions → Contents: Read and write.
  4. Generate token → dán vào ô trên → bấm Tạo Két Token ở Mục 1 để không phải dán lại nữa!
3. Ghép nối nhanh sang điện thoại / máy khác
